# Wifi-Death-V1
A ESP32 based wifi hacking tool with esp32 c3 and 0.96 inch oled dsplay

⚠️ Disclaimer ⚠️
This project is intended for educational and ethical purposes only. The use of deauthentication attacks may be illegal in your country or region. Please ensure that you have proper authorization before using this firmware to test any network.

Overview
Wifi Death V1 is a custom firmware for the ESP32 board that enables WiFi scanning, deauthentication attacks, and includes support for a 0.96-inch OLED display. The firmware is designed to leverage the powerful capabilities of the ESP32, making it a versatile tool for network analysis and testing. Schematics & PCB data is provided
